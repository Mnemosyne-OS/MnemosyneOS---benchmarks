LFM3-1.7B does not compile on the NPU yet. Intel's NPU compiler sees two attention masks (full and sliding-window) on the same node and stops, under every setting we tried. Reported to Intel: openvinotoolkit/openvino#39790. On the Arc and the CPU it runs well.

Every number, and how it was measured

  • Machine: Intel Core Ultra 7 155H (Arc iGPU, AI Boost NPU), NVIDIA RTX 4050 Laptop 6 GB capped at 25 W by the laptop's power profile, 32 GB RAM, Windows 11.
  • GGUF runs: llama.cpp through node-llama-cpp 3.22.3, all layers on the GPU unless marked partial, context 4,096 (8,192 for the long prompt), temperature 0, one warm-up pass, median of 3 runs.
  • Each file comes from Hugging Face and is checked by its sha256; Q4_K_M unless the table says otherwise.
  • A bench queue runs one measurement at a time, so no run slows another. Failed or invalid runs were re-queued and measured again.
  • Time to first word = 4,096 ÷ prompt tokens per second + time to the first generated token.
